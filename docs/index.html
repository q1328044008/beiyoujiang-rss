之前为什么「只有标题」？

beiyoujiang.com 的帖子页是前端渲染的单页应用，服务器返回的 HTML 里只有一段「加载中」占位：

<img src="/images/load.gif"> 主人别急~ 杯酱正在努力装填玩具弹药...

而「閲讀」的阅读器默认会判断 feed 自带正文够不够「结构化」，不够就自己去抓条目链接做正文提取——抓到的既然是占位文字，正文就被覆盖了，于是只剩标题。

现在做了什么

  • 正文重排成真正的段落：一段一 <p>、一图一 <p>，评论楼层也各自成块，App 会直接使用 feed 内容。
  • 每篇帖子额外生成静态页（/p/帖子ID.html），feed-app.xml 指向它们，就算 App 坚持抓全文也能抓到真内容。
  • 配图全部镜像到本站（原站有防盗链，别的站引用会 403），图片不会再裂开。
  • 生成时自动自检：结构块数量、文字长度、相对链接、镜像页是否齐全，不达标就报警。
python generate_feed.py --plates 2 --out feed.xml

1 = 大型倒模，2 = 杯酱论坛，3 = 杂鱼茶话，可写 1,3 组合。

本站内容为 18+ 成人玩具交流社区的公开帖子摘要，仅面向成年读者。
